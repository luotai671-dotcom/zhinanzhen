## 一、风控底层解密：机房 IP（Data Center）vs 原生住宅 IP（Residential）

当你在浏览器中访问 OpenAI 或 TikTok 时，对端部署的 Cloudflare 或自研反欺诈防火墙会在 50 毫秒内对你的 IP 展开多维度的身份画像审查：

### 1. IP 属性分类（Type 字段）
- **机房数据中心 IP（Data Center IP）**：
  - 属于亚马逊云（AWS）、谷歌云（GCP）、阿里云国际、搬瓦工、DigitalOcean 等商业机房服务器分配的 IP；
  - **风控逻辑**：正常的人类绝不可能坐在服务器机柜里打字写代码。因此，OpenAI 和 Anthropic 对所有机房 IP 实施了**“默认有罪推断”**，只要该 IP 上有人批量爬取或发起异常请求，整个 IP 段便会被连坐封禁。
- **原生住宅双 ISP IP（Residential Broadband）**：
  - 由海外当地电信运营商（如美国 AT&T、Verizon、Comcast，英国 BT，日本 NTT，香港 HKT）直接分配给当地居民家庭宽带的真实 IP；
  - 在 IPInfo、MaxMind、Scamalytics 等权威反作弊库中，其 `Type` 明确标记为 `ISP / Broadband`。
  - **风控逻辑**：对端风控系统识别到这是一个真实的海外家庭在上网，反欺诈评分极低（Fraud Score < 10），因此直接放行，免除验证码和 5 秒盾。

### 2. 多人共用与黑名单连坐机制
劣质廉价机场一个节点往往挂载了数千名用户。当其中一人违规操作导致 IP 被拉黑后，挂在该节点下的所有普通用户瞬间全部报错。而优质原生住宅专线采用动态分配与严格的滥用清洗机制，保障每个节点的长期纯净。

## 四、客户端 AI 防封与防关联关键实操指南

拥有了优质原生住宅专线后，客户端的科学配置同样必不可少：

1. **必须开启 TUN 虚拟网卡模式**：
   - Cursor、ChatGPT 官方桌面版 App、Claude 桌面客户端等现代生产力工具，底层网络流量经常绕过系统的普通代理设置；
   - 在 Clash Verge Rev 或 Shadowrocket 中开启 `TUN 模式`，强制系统底层虚拟网卡接管所有 AI 进程流量，彻底避免真实 IP 泄漏。
2. **将 AI 域名固定分流至原生住宅专线**：
   - 在客户端规则中，将以下顶级域名精确分流至闪电鼠或榴莲云的原生住宅代理组：
     - `*.openai.com`
     - `*.chatgpt.com`
     - `*.anthropic.com`
     - `*.claude.ai`
     - `*.cursor.com`
3. **禁用浏览器 WebRTC 泄漏真实 IP**：
   - 现代浏览器（Chrome / Edge）的 WebRTC 功能可能会在后台向对端泄露你本地的内网私有 IP 甚至公网真实 IP；
   - 建议在浏览器安装 `WebRTC Control` 插件，将其设置为完全禁用；或在防关联指纹浏览器中统一关闭 WebRTC，确保对端探测到的网络指纹 100% 干净一致。
